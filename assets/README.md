# Brand assets

## Logo
- `logo.png` — the TechJam mark used in the header & footer. **Swap this file** (keep the name, or update the `src` in `index.html`) to use the official asset. A transparent-background **SVG** will render crispest at all sizes.
- `favicon.svg` — browser-tab icon (a simple gradient placeholder mark).

## Colours
All brand colours live in **one place**: `../css/theme.css`, under the `:root` block (`--brand-*`).
The placeholders approximate the logo's purple → magenta gradient. Edit those values to match
TechJam's exact brand and the whole site (buttons, gradients, accents, icons) updates automatically —
`styles.css` never hard-codes a colour.
